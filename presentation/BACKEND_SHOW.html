# Phân hệ (Module) Endpoint API Phương thức Chức năng & Logic cốt lõi Đối tượng phục vụ
01 Property Module /properties/units GET Bóc tách 4 khoản phí All-in Cost: Tiền thuê gốc + Phí BQL (9.5k/m2) + Gửi xe + Điện nước (300k/người). Gắn badge căn hời. Khách Thuê (Màn 1)
02 AI Matchmaker /matchmaker/recommend POST Quét rổ hàng 30s, loại bỏ căn vượt trần ngân sách, xếp hạng Top 3 căn hời nhất kèm giải trình tiết kiệm hàng tháng. Khách Thuê (Màn 2)
03 Booking & Sảnh 1-chạm /bookings/confirm
/bookings/:id/lobby-checkin		 POST Xác thực OTP SĐT diệt môi giới ảo/no-show. Nút 1-chạm Zalo T-10m [📍 Tôi đã có mặt tại sảnh], Host ra quẹt thẻ đón trong 60s. Khách Thuê (Màn 3, 4)
04 Host Dispatch PWA /dispatch/tickets/:id/accept
/dispatch/tickets/:id/reveal-key		 POST Điều phối 3 tầng SLA (5p -> 3p <=500m -> Area Lead). Cấp mã mở cửa Vault JIT tại phòng, 0 dùng Lockbox, gửi alert Zalo cho chủ nhà. Field Host (Màn 1-3)
05 VietQR Cọc 2M /deposits/generate-vietqr
/deposits/webhook-vietqr		 POST VietQR động có Attribution Lock (host_id). Webhook gạch nợ <= 5s, khóa căn HOLDING 7 ngày, Conflict Resolver tự động hủy lịch trùng. Khách Thuê (Màn 5)
06 FPT.AI eKYC /identity/ekyc/verify POST Xác thực CCCD 2 mặt, Face Liveness Detection, đối chiếu C06. Cơ chế Zero-Storage RAM 0 byte lưu ổ cứng tuân thủ NĐ 356/2025. Khách Thuê (Màn 6)
07 Contract & E-Sign /contracts/holding-agreement/sign
/contracts/mandate/create		 POST Ký số Canvas + Zalo OTP, niêm phong SHA-256 + Dấu thời gian RFC 3161. Trao danh bạ thợ ngoài uy tín Ocean Park. Ký Mandate độc quyền. Khách & Chủ Nhà
08 Landlord Ở Nhà 100% /landlord/dashboard
/landlord/mandates/request-exit		 GET/POST Bảng điều khiển 0km đi lại, 0 phút mở cửa. Giám sát cọc 2M, Audit Trail mở cửa. Kích hoạt thoát ủy quyền linh hoạt 15 ngày (khi căn Available). Chủ Nhà (Màn 1-4)
09 Handover Passport /handovers POST Hộ chiếu bàn giao 10 hạng mục nội thất + công tơ điện nước Host nhập tay + ảnh timestamp. Ví Host nhận ngay +450.000đ. Field Host (Màn 4)
10 Admin BI & Heatmap /admin/bi-funnel
/admin/exclusive-inventory		 GET Phễu chuyển đổi 6 giai đoạn (no-show 3.8%), Occupancy Heatmap Sapphire 1 & 2. Quản lý 128 căn hộ độc quyền & theo dõi thoát 15 ngày. Admin (Mod 1, 2)
11 Dynamic Commission /admin/commission-engine
/admin/dispatch-sla		 GET/POST Giám sát SLA ca trực (báo động đỏ >3p). Cấu hình 4 biến phí thù lao, tính Weekly Payout, xuất file chuyển khoản ngân hàng 1-chạm. Admin (Mod 3, 4)
